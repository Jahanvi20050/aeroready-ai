# NASA C-MAPSS Turbofan Engine Degradation Dataset

## Overview

This directory contains the turbofan engine degradation dataset used by **AeroReady AI** for Remaining Useful Life (RUL) estimation. The dataset was generated by the NASA Prognostics Center of Excellence (PCoE) using the Commercial Modular Aero-Propulsion System Simulation (C-MAPSS).

The current version focuses on the **FD001** subset:
- **Operating Conditions:** Sea Level (Single condition)
- **Fault Mode:** High-Pressure Compressor (HPC) Degradation
- **Training Engines:** 100 run-to-failure engine trajectories
- **Test Engines:** 100 trajectories ending prior to system failure

---

## Expected Files

To run training and evaluation, ensure the following files exist in this folder (`aeroready-ai/data/`):

| File | Description | Shape / Records |
| :--- | :--- | :--- |
| `train_FD001.txt` | Complete run-to-failure sensor records for 100 engines | 20,631 rows, 26 columns |
| `test_FD001.txt` | Sensor records ending prior to failure for 100 engines | 13,096 rows, 26 columns |
| `RUL_FD001.txt` | Ground-truth Remaining Useful Life cycles for the 100 test engines | 100 rows, 1 column |
| `readme.txt` | Official NASA documentation & sensor definitions | Reference documentation |

## Dataset Schema (26 Space-Separated Columns)

Each row represents a snapshot of data taken during a single operational cycle:

| Column Index | Column Name | Description | Units |
| :--- | :--- | :--- | :--- |
| 1 | `engine_id` | Engine unit number (1 to 100) | Integer ID |
| 2 | `cycle` | Operational flight cycle count | Cycles |
| 3 | `op_setting_1` | Altitude / operational setting 1 | Normalized |
| 4 | `op_setting_2` | Mach number / operational setting 2 | Normalized |
| 5 | `op_setting_3` | Throttle resolver angle / setting 3 | Normalized |
| 6 | `sensor_1` | Total temperature at fan inlet | °R |
| 7 | `sensor_2` | Total temperature at LPC outlet | °R |
| 8 | `sensor_3` | Total temperature at HPC outlet | °R |
| 9 | `sensor_4` | Total temperature at LPT outlet | °R |
| 10 | `sensor_5` | Pressure at fan inlet | psia |
| 11 | `sensor_6` | Total pressure in bypass-duct | psia |
| 12 | `sensor_7` | Total pressure at HPC outlet | psia |
| 13 | `sensor_8` | Physical fan speed | rpm |
| 14 | `sensor_9` | Physical core speed | rpm |
| 15 | `sensor_10` | Engine pressure ratio (P50/P2) | -- |
| 16 | `sensor_11` | Static pressure at HPC outlet | psia |
| 17 | `sensor_12` | Ratio of fuel flow to Ps30 | pps/psia |
| 18 | `sensor_13` | Corrected fan speed | rpm |
| 19 | `sensor_14` | Corrected core speed | rpm |
| 20 | `sensor_15` | Bypass Ratio | -- |
| 21 | `sensor_16` | Burner fuel-air ratio | -- |
| 22 | `sensor_17` | Bleed Enthalpy | -- |
| 23 | `sensor_18` | Demanded fan speed | rpm |
| 24 | `sensor_19` | Demanded corrected fan speed | rpm |
| 25 | `sensor_20` | HPT coolant bleed | lbm/s |
| 26 | `sensor_21` | LPT coolant bleed | lbm/s |

> Note: For the FD001 dataset, certain sensors (`sensor_1`, `sensor_5`, `sensor_10`, `sensor_16`, `sensor_18`, `sensor_19`) exhibit zero variance because operating conditions are fixed at sea level. The preprocessing pipeline detects and removes these uninformative channels.

## How to Download (If Missing)

If these files are missing, you can obtain them from:
1. **NASA Prognostics Data Repository:**
   - Link: https://www.nasa.gov/intelligent-systems-division/discovery-and-systems-health/pcoe/pcoe-data-set-repository/
   - Archive Name: `CMAPSSData.zip`
2. **Kaggle Mirror:**
   - Link: https://www.kaggle.com/datasets/behrad3d/nasa-cmaps
3. Place `train_FD001.txt`, `test_FD001.txt`, and `RUL_FD001.txt` inside this `data/` directory.
